# Contributing

## Local setup

Install Node.js 22 and pnpm 10.24.0, then run:

```sh
pnpm install
pnpm check
```

`pnpm dev:site` serves the portfolio at `http://localhost:8080`.
`pnpm dev:printor` serves printor at `http://127.0.0.1:5173`.

## Editing the portfolio

Page templates and styles live in `apps/site/src/`. Project and post Markdown
lives in `apps/site/src/content/{en,ru}/`. Keep paired translations on the same
`slug` and link them with `translationUrl`.

To add a post, copy an existing Markdown file, change its front matter and
body, and set `draft: true` until it is ready. Use `pnpm build:drafts` to
preview draft posts.

Replace:

- `apps/site/src/logo.svg` to update the automatically optimized inline logo.
- `docs/main.pdf` to update `/cv.pdf`.
- `apps/site/src/_data/site.js` to add confirmed contact links.
- `apps/site/src/_data/tools.js` when a tool URL or status changes.

Do not edit `apps/site/_site/`; it is generated by `pnpm build`.

## Editing printor

- `apps/printor/src/types.ts` — the stage model, ranges, and defaults.
- `apps/printor/src/engine/frameParams.ts` — how a range collapses to one
  value per frame. All randomness lives here.
- `apps/printor/src/engine/shaders.ts` — GPU effect code.
- `apps/printor/src/components/` — controls and panels.
- `apps/printor/src/shared/` — printor's vendored copy of the tool shell and
  design tokens. `packages/shell/` and `packages/tokens/` no longer feed it.

Adding a parameter touches four files in lockstep: `types.ts` (field, default,
and clamp), `frameParams.ts` (draw it per frame), `shaders.ts` (uniform and
use), `Renderer.ts` (upload), plus a control in `components/StageInspector.tsx`.

Keep all processing local. Do not add analytics, endpoints, remote assets, or
`Math.random()` anywhere in the app. New frame variation must derive from
`hash(seed, frame, stage, channel)`; `tests/privacy.test.ts` enforces both.

Do not edit `apps/printor/dist/`; Vite generates it.

## Before publishing

Run `pnpm check`. Confirm both output directories exist:

- `apps/site/_site/`
- `apps/printor/dist/`

Use Conventional Commits, for example:

```sh
git commit -m "feat(printor): add paper banding controls"
```
