# 02 — ТЗ: printor

Читать после `00-CONTEXT.md`. Начинать только после того, как сайт задеплоен.
Полномочия агента (что решать самому, что спрашивать) — `00-CONTEXT §3`. В этом ТЗ описано **что** должно получиться; **как** — на усмотрение агента, при условии записи нетривиальных решений в `docs/decisions.md`.

---

## 1. Продукт в одном абзаце

**printor** (всегда строчными, мелким кеглем) берёт видео и делает вид, что его разложили на кадры, напечатали на принтере и отсканировали — каждый лист по-своему кривой, с разным качеством печати, следами бумаги и, если нужно, поверх чужих распечаток (палимпсест). Всё считается **на устройстве пользователя** через WebGL2; ни один кадр не покидает браузер. Бесплатно, без аккаунта, без подписки, оффлайн.

Ключевое отличие от аналогов вроде effect.app — не фичи, а три вещи: **локальность**, **бесплатность**, **детерминированная рандомизация по кадрам** (главный источник «живости» оттиска).

## 2. Архитектура

```
File → Demux/Decode (WebCodecs) → FrameSource
     → Timebase (fps resample)
     → Effect Stack (WebGL2 ping-pong FBO passes)
     → Preview (proxy res)  |  Export (full res → Encode/Mux → File)
```

| Слой | Решение | Fallback |
|------|---------|----------|
| Runtime | Vite + TypeScript, SPA, PWA (оффлайн) | — |
| UI | React 19 + Zustand. **Без Tailwind и UI-китов** — стили на `tokens.css` из `packages/tokens` | — |
| Декод | **WebCodecs** `VideoDecoder` + демуксер (`mediabunny`, при проблемах `mp4box.js`) | `<video>` + `requestVideoFrameCallback` + `drawImage` (медленно, только для превью) |
| Рендер | **WebGL2**, каждый эффект — один или несколько fragment-проходов, ping-pong между двумя FBO, формат `RGBA16F` (при отсутствии — `RGBA8` + sRGB-коррекция) | сообщение о неподдерживаемом браузере |
| Энкод | WebCodecs `VideoEncoder` (H.264 → MP4, VP9 → WebM) + муксер | ZIP из PNG (`fflate`) — **всегда доступен**, это базовый путь экспорта |
| Хранение | IndexedDB: автосейв проекта (параметры, не кадры), библиотека пресетов, пользовательские текстуры | — |
| Воркеры | декод, энкод и full-res рендер — в Web Worker с OffscreenCanvas; UI-поток не блокируется | однопоточный режим с предупреждением |

Бюджет бандла: ориентир **≤300 KB** gzip без учёта текстур, текстуры — по требованию. Это цель, а не жёсткий лимит: **правило 14 KB к printor не относится** — это приложение, а не страница. Если функциональность требует больше, агент увеличивает бюджет и пишет причину в `docs/decisions.md`.

### Определяющее правило рандомизации

Никакого `Math.random()` в конвейере. Единственный источник случайности:

```ts
rand(globalSeed, frameIndex, layerId, channel) → float32 in [0,1)
```
Реализация: 32-битный хеш (PCG/xxhash32) в JS + идентичный хеш в GLSL, получающий `u_seed`, `u_frame`, `u_layer` юниформами. Следствия, которые обязаны выполняться:
- один и тот же пресет + сид = **побайтово тот же результат** на любой машине;
- превью и финальный экспорт совпадают покадрово (с поправкой на разрешение);
- пресет полностью описывается JSON'ом и переносится между людьми.

Каждый слой имеет `jitter` (0…1) — амплитуду покадрового разброса своих параметров — и флаг `perFrame`. `jitter=0` → эффект статичен и «цифров»; `jitter=0.3` → каждый лист напечатан чуть иначе. Это главный сюжет продукта, вынести в UI на видное место (макро-слайдер **CHAOS**, который пропорционально двигает `jitter` всех активных слоёв).

## 3. Конвейер эффектов

Стек **переупорядочиваемый** drag'n'drop; у каждого слоя: `on/off`, `opacity`, `blendMode`, `jitter`, `perFrame`, кнопка `randomize`, кнопка `reset`. Порядок по умолчанию — снизу вверх (первым применяется нижний):

```
 10  PALIMPSEST OVERLAY      ← последний, поверх всего
  9  PAPER CUTOUT
  8  PAPER SCAN
  7  DITHER  /  HALFTONE     ← взаимоисключающий переключатель режима
  6  NOISE
  5  LAYER MIX (texture)
  4  MOTION BLUR
  3  LEVELS
  2  CURVES
  1  TIMEBASE (fps)          ← первый, не двигается со дна
```

### 3.1 TIMEBASE (не отключается, всегда в основании)
| Параметр | Тип | Дефолт | Примечание |
|---|---|---|---|
| `sourceFps` | readonly | из файла | |
| `targetFps` | int 1…30 | 12 | ядро эффекта «покадровости» |
| `mode` | `hold` \| `nearest` \| `blend` | `hold` | `hold` даёт честный степ-анимационный вид |
| `shutter` | float 0…1 | 0.5 | сколько исходных кадров усредняется в один — источник честного motion blur |
| `frameDrop` | float 0…1 | 0 | вероятность выпадения кадра (детерминированно от сида) |
| `trimIn/trimOut` | time | вся длина | |

Выводит **`frameCount`** — оно показывается в UI постоянно и нужно для палимпсеста.

### 3.2 CURVES
RGB + отдельные каналы R/G/B; сплайн по контрольным точкам; пресеты `linear`, `contrast`, `crush`, `filmic`. Реализация — LUT 256×1 в текстуре.

### 3.3 LEVELS
`inBlack`, `inWhite`, `gamma (midpoint)`, `outBlack`, `outWhite`, на RGB и по каналам. `jitter` двигает `midpoint` покадрово — это самая заметная имитация «в принтере кончается тонер».

### 3.4 MOTION BLUR
Два режима:
- `temporal` — накопление N соседних исходных кадров по `shutter` (физически верно);
- `directional` — как в референсе: `strength` 0…64, `angle` 0…360, `box` on/off, `bothDirections` on/off.
Плюс `opacity`, `blendMode`, маска: `enableMask`, `maskCenter[x,y]`, `maskRadius`, `maskFeather`.

### 3.5 LAYER MIX (наложение текстуры)
| Параметр | Значения |
|---|---|
| `texture` | из библиотеки или пользовательская загрузка (PNG/JPG/WebP) |
| `fitType` | `fill` \| `stretch` \| `tile` |
| `textureScale` | 0.1…8 |
| `blendChannel` | `gray` \| `r` \| `g` \| `b` \| `luma` |
| `currentLayerRamp`, `underlyingLayerRamp` | по 4 ручки, как в референсе (аналог «Blend If») |
| `blendMode` | normal, multiply, screen, overlay, soft-light, hard-light, darken, lighten, difference, subtract |
| `opacity` | 0…1 |
| `jitter` | сдвигает UV и вращает текстуру покадрово → «каждый лист лёг иначе» |

**Библиотека текстур.** Владелец кладёт свои сканы в `apps/printor/public/textures/`. Агент:
1. описывает формат — `textures/manifest.json`: `id`, `name`, `file`, `tiles: bool`, `defaultScale`, `author`, `license`;
2. **генерирует процедурные плейсхолдеры** (6 шт.: `paper-plain`, `paper-crumpled`, `newsprint`, `receipt-thermal`, `xerox-dust`, `fold-lines`), чтобы разработка не ждала ассетов;
3. пишет в README раздел «How to add a texture» на три строки;
4. следит, чтобы плейсхолдеры автоматически вытеснялись реальными файлами при совпадении `id`.

Формат ассетов: WebP/AVIF, ≤120 KB, ленивая загрузка. Чужие текстуры (в т. ч. Texturelabs) в репозиторий не попадают ни при каких условиях.

Слой можно добавить в стек **несколько раз** (в референсе так и сделано).

### 3.6 NOISE
`amount`, `size` (1…8 px), `type`: `gaussian` \| `uniform` \| `grain`, `mono` on/off, `perFrame` (по умолчанию **on** — статичный шум мгновенно выдаёт цифру).

### 3.7 DITHER / HALFTONE (переключатель режима)

**DITHER**
| Параметр | Значения |
|---|---|
| `algorithm` | `bayer2` \| `bayer4` \| `bayer8` \| `blueNoise` \| `floydSteinberg` \| `atkinson` |
| `levels` | 2 (1-бит) …16 |
| `colorMode` | `mono` \| `duotone` \| `palette` \| `cmyk` |
| `palette` | набор риsо-красок: black, fluor pink, orange, blue, green + пользовательская |
| `threshold`, `contrast`, `matrixScale` | |
| `serpentine` | для error-diffusion |

`floydSteinberg` и `atkinson` последовательны и на GPU в лоб не считаются: реализовать отдельным CPU/WASM-проходом на пониженном разрешении (или в compute-эмуляции построчно). Если это тормозит превью — в превью подменять на `blueNoise`, а в экспорте считать честно, **явно показав это в UI** («preview approximation»).

**HALFTONE**
| Параметр | Значения |
|---|---|
| `shape` | `dot` \| `line` \| `ellipse` \| `square` \| `cross` |
| `lpi` | 10…150 (частота растра) |
| `angleK/C/M/Y` | по умолчанию 45 / 15 / 75 / 0° |
| `channels` | `mono` \| `duotone` \| `cmyk` |
| `sharpness` | мягкость края точки |
| `dotGain` | имитация растискивания |
| `misregistration` | сдвиг каналов, `jitter` делает его покадровым — самый узнаваемый признак настоящей печати |

### 3.8 PAPER SCAN
| Параметр | Смысл |
|---|---|
| `paperTint`, `paperBrightness`, `paperContrast` | цвет и тон бумаги |
| `bandingAmount`, `bandingFrequency` | полосы протяжки/лампы сканера |
| `rollerStreaks` | вертикальные полосы грязного вала |
| `skew` (°), `offsetX/Y`, `scaleJitter` | лист лёг на стекло криво — покадрово |
| `edgeShadow`, `edgeVignette` | тень от крышки сканера |
| `blurriness`, `threshold`, `ringing` | оптика скана (из референса; отрицательный `blurriness` = шарп с ореолом) |
| `dropoutProbability` | редкие «пропечатки»/полосы утери данных |

### 3.9 PAPER CUTOUT
| Параметр | Смысл |
|---|---|
| `seed` | форма разрыва |
| `edgeType` | `torn` \| `cut` \| `perforated` |
| `edgeRoughness`, `edgeDepth` | |
| `rotation`, `sizeVariation`, `widthVariation`, `heightVariation`, `uvShift` | покадровый разброс (как в референсе) |
| `shadow` | мягкая тень листа на фоне — **единственная тень во всём проекте** |
| `background` | цвет подложки или прозрачность (влияет на альфу экспорта) |

### 3.10 PALIMPSEST OVERLAY
Отдельный слой (технически — `layer mix`, но со своим UI, потому что это «фича-крючок» продукта).

- Загрузка **последовательности** изображений (мультивыбор или ZIP/папка).
- UI показывает: `frames: 25 · images: 25 ✓` либо `images: 12 — mapping: cycle`.
- `mapping`: `oneToOne` \| `cycle` \| `randomNoRepeat` \| `randomAny` (детерминированно от сида).
- `blendMode` по умолчанию `multiply`, `opacity`, `perFrameTransformJitter` (сдвиг/поворот/масштаб каждого листа).
- Порядок: `overlayUnder` (наш кадр напечатан **поверх** чужой распечатки — дефолт) или `overlayOver`.
- Подсказка в UI: сканы чеков, тетрадных страниц, ведомостей.

## 4. Интерфейс

```
┌──────────┬───────────────┬───────────────────────────┬────────────┐
│ PRESETS  │ LAYERS        │        CANVAS             │ INSPECTOR  │
│ library  │ ▸ drag-order  │   [ preview, fit/100% ]   │ параметры  │
│ user     │ ▸ on/off, eye │                           │ активного  │
│          │ ▸ + add layer │   frames: 25 · 1080×1350  │ слоя       │
├──────────┴───────────────┴───────────────────────────┴────────────┤
│ ◀ ▶ ⟳  0:00.9 / 5.0s   12 fps   [SEED 8471 ⟳]  CHAOS ▁▂▃  EXPORT │
│ ├─────── frame ticks: каждая засечка = один выходной кадр ────────┤
└───────────────────────────────────────────────────────────────────┘
```

Требования к UI:
- Визуально — продолжение сайта: `--paper`/`--ink`, mono-лейблы uppercase, хайрлайны, `border-radius:0`, **цвета нет**. Активные состояния, включённые слои и кнопка рендера обозначаются «штампом» — инверсным блоком (см. `00-CONTEXT §2.3`).
- printor — первый инструмент из нескольких, поэтому оболочка (шапка, футер, страница `/support`, PWA-манифест, экран ошибок) выносится в `packages/shell` и переиспользуется следующими. printor может позволить себе собственную подпись внутри канваса — но не ценой общей системы.
- **Засечки таймлайна = выходные кадры**, а не секунды. Это честно отражает суть инструмента.
- Каждый параметр: имя слева (mono, lowercase), число справа, слайдер под ними, `alt+click` — сброс, ввод значения с клавиатуры.
- Горячие клавиши: `space` play/pause, `←/→` кадр, `shift+←/→` 10 кадров, `cmd+z/shift+cmd+z` undo/redo (история на 50 шагов), `r` reroll seed, `e` export.
- Сравнение: удержание `\` показывает исходник.
- Пресеты: `save`, `duplicate`, `export .printor.json`, `import`, `share by link` (пресет в URL-хеше — это просто текст, никакой загрузки на сервер). Встроенные: `Receipt scan`, `Riso duotone`, `Xerox 3rd generation`, `Newsprint halftone`, `Fax 1994`, `Clean 1-bit`.
- Пустое состояние: одна зона «Drop a video here», под ней строка «Everything is processed on your device. Nothing is uploaded.»
- Ошибки — по делу: «This browser can't decode MP4. Use Chrome 111+ or export a PNG sequence.» — без извинений и без общих слов.

## 5. Импорт и экспорт

**Вход:** `.mp4`, `.mov`, `.webm` , последовательность PNG/JPG, GIF, одно изображение. Лимиты : 1080p, 30 с, 300 кадров — при превышении честное предупреждение и предложение обрезать, а не молчаливый отказ.

**Выход:**
| Формат | Примечание |
|---|---|
| **PNG sequence в ZIP** | базовый путь, работает везде, поддерживает альфу — реализовать первым |
| **MP4 (H.264)** | WebCodecs, выбор битрейта/качества, 24 fps контейнера при любом `targetFps` (кадры дублируются) |
| **WebM (VP9)** | альтернатива, поддерживает альфу |
| **GIF** | `gifenc`, с квантованием под палитру дизеринга |
| **APNG** | опционально |
| Звук | v1.1, passthrough дорожки оригинала |

Экспорт: прогресс по кадрам, оценка оставшегося времени, **отмена**, рендер вне UI-потока. Разрешение — исходное или пресеты кропа `1:1 / 4:5 / 9:16 / 16:9` (для соцсетей). Превью считается на прокси ≤720p, экспорт — на полном разрешении, результат должен совпадать по сиду.

## 6. Производительность и совместимость

- Цель: 1080p превью ≥15 fps на MacBook Air M1 в Chrome при 8 активных слоях.
- Все проходы — на GPU, ресайз только шейдером, никаких `getImageData` в цикле кадров.
- Кадры-исходники кэшируются как GPU-текстуры кольцевым буфером (лимит по VRAM, LRU-вытеснение).
- Поддержка: Chrome/Edge 111+, Safari 17+ (частично: при отсутствии `VideoEncoder` остаётся ZIP-экспорт), Firefox 130+. Проверка возможностей на старте, честная матрица «что работает, что нет» на странице `/support`.
- Мобильные : desktop-first, на телефоне — читаемая заглушка.
- Оффлайн: service worker кэширует приложение; после первого визита работает без сети.

## 7. Приватность, лицензия, посадочная страница

- Ноль сетевых запросов после загрузки приложения. Проверяется тестом: рендер эталонного ролика при отключённой сети.
- В `<head>` — CSP `connect-src 'none'`. Это техническая гарантия обещания, а не текст в футере.
- Лицензия кода — **AGPL-3.0** : любой, кто поднимет printor как сервис, обязан открыть изменения. Прямое следствие мотивации проекта.
- Текстуры — CC0 или CC BY (только собственные/процедурные).
- `printor.<domain>` = приложение сразу, без лендинга-прокладки. Под фолдом — короткий блок: что это, три пресета-примера (готовые GIF ≤200 KB), «Free. Local. No account.», ссылка на репозиторий и на основной сайт.
- README на английском: скриншот, три строки о продукте, установка, архитектура, `CONTRIBUTING.md`.
